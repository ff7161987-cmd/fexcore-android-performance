# JIT and IR audit

## JIT compilation path

The ARM64 JIT lowers an IR block into a temporary emission buffer, performs the required relocation and exit-link work, reserves space in the shared code buffer, copies the completed block, and publishes the block through the existing lookup/linking infrastructure. The shared allocator is therefore a compilation-time contention point rather than a guest execution instruction sequence.

The applied change is limited to `SharedCodeBufferManager::AtomicAllocateBuffer`. Its cursor is an atomic linear-allocation pointer. Each successful compare-exchange reserves a unique aligned range, while the generated bytes are written only after reservation. The cursor does not publish generated bytes, guest memory, or cache invalidation state. Explicit relaxed ordering is sufficient for this role and removes stronger ARM64 ordering constraints without changing the allocation algorithm.

## IR and register allocation

The pass manager invokes flag preparation, register allocation, move coalescing, and post-allocation cleanup. The register allocator tracks GPR/FPR classes, static registers, spill slots, pair constraints, and flags. These invariants are tightly coupled to the ARM64 ABI and to signal/syscall paths. No new IR pass was added because a valid transformation would require representative x86_64 traces, instruction-count measurements, and cross-architecture semantic tests.

## Branch and code-cache interaction

Direct exits use linkable branches and fallback thunks; indirect exits use the per-thread L1 lookup path and the dispatcher fallback. The JIT also preserves guest RIP, call-return state, and required flags around exits. These mechanisms were retained. Removing a lookup or changing branch selection without a device trace could create correctness failures on self-modifying code, invalidation, or far code-buffer placement.

## Result

The only JIT-side code change in this release is the relaxed ordering of the shared allocation cursor. All other observations are recorded as constraints for future work rather than presented as completed performance gains.
